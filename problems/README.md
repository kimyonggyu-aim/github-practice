# 오늘의 문제 5개

답은 `answers/내이름.md`에 적어요. 정답뿐 아니라 이유도 한 문장씩 써 봐요.

## 1. 과일 나누기

사과 12개를 친구 3명이 똑같이 나누어 가져요. 한 명이 몇 개씩 가질까요?

도움말: 그림으로 세 묶음을 그려도 좋아요.

## 2. 규칙 찾기

`2, 4, 6, 8, ?`

물음표에 들어갈 수는 무엇일까요? 어떤 규칙을 찾았나요?

## 3. 로봇에게 설명하기

로봇이 색연필을 정리하려고 해요. 아래 행동을 알맞은 순서로 써 주세요.

- A: 필통을 닫아요.
- B: 색연필을 필통에 넣어요.
- C: 필통을 열어요.

순서가 중요한 이유도 생각해 봐요.

## 4. 잘못된 계산 고치기

지우가 `7 + 5 = 11`이라고 썼어요. 맞게 고치고, 어떻게 확인했는지 설명해 주세요.

## 5. 내 공책 찾기

친구들과 같은 문제를 풀 때 다음 중 어디에 내 풀이를 쓰면 좋을까요?

- A: 모두가 받는 `main`에서 바로 수정해요.
- B: `main`에서 만든 내 이름 브랜치에서 수정해요.
- C: 친구 이름 브랜치에서 수정해요.

고른 답과 이유를 적고, 오늘 만든 내 브랜치 이름도 써 주세요.

## 다 풀었다면

풀이를 저장하고 커밋한 뒤 제출해요. 친구 한 명의 설명을 읽고 “이 부분은 이렇게 생각한 거야?”라고 물어봐요. 서로 다른 풀이도 있을 수 있어요.
